# 🎮 Mini Battle Royale

Браузерная 2D игра в стиле Fortnite. Solo (vs ботов) и Multiplayer (Node.js сервер).

## ▶ Быстрый старт (Solo)

Просто открой **`index.html`** двойным кликом. Выбери "SOLO" → играй.

## 🌐 Multiplayer

### 1. Установи Node.js (если ещё нет)
Скачай с https://nodejs.org/ (LTS).

### 2. В папке игры открой PowerShell и выполни:
```powershell
npm install ws
node server.js
```

### 3. Подключение
- **Хост:** открой `http://localhost:8080` в браузере.
- **Друзья (в той же Wi-Fi сети):** открой `http://<твой_LAN_IP>:8080`.
  - Узнать IP: `ipconfig` → "IPv4 Address" (обычно `192.168.x.x`).
- **Через интернет:** пробрось порт 8080 на роутере, или используй `ngrok http 8080`.

В меню выбери "MULTIPLAYER", укажи никнейм и сервер (по умолчанию `ws://localhost:8080`).
Матч стартует автоматически при ≥2 игроках после 10-секундного отсчёта.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | Движение |
| `Shift` | Спринт |
| Мышь | Прицел |
| ЛКМ | Стрельба |
| `R` | Перезарядка |
| `1` / `2` / `3` / `4` | Пистолет / АК / Дробовик / Снайперка |
| Колесо мыши | Переключение оружия |
| ПКМ (с снайперкой) | Прицел/зум 2× |
| `Q` | Режим стройки вкл/выкл |
| `B` / `F1` / `F2` / `F3` | Цикл / Стена / Пол / Рампа |
| ЛКМ (в режиме стройки) | Поставить структуру |
| `M` | Звук вкл/выкл |
| `N` | Музыка вкл/выкл |

## 🌪 Геймплей

- Карта 4000×4000, деревья и камни как укрытия.
- Подбирай 💚 аптечки (+35 HP), 🟡 патроны и 🔫 оружие.
- Фиолетовая зона "бури" сужается каждую минуту и наносит урон вне круга.
- Последний выживший побеждает.
